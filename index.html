Nhập từ file Excel kế hoạch quốc tế

Chọn file Ke_hoach_Phat_trien_Thi_truong_Quoc_te_H2-2026_H1-2027.xlsx — hệ thống đọc 3 sheet (Đối tác · Pipeline · Sự kiện), tự chuẩn hoá tên quốc gia về mã ISO, tách trạng thái quan hệ, gộp 2 lớp tên Hàn/Nhật, và nạp theo lô.
