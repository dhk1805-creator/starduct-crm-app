2. The single business flow

Distributor registers a project (ERP) → BO verifies → Leadership approves (CRM) → project enters CRM → quotation → order/production request → manufacturing → delivery → revenue → receivables

Every role owns one step of this flow. The CEO dashboard reads directly from the data you create — no manual reports. No number enters the system without an authorised person.

7. Distributors — Parent & Child accounts

Distributor codes used in all communication — Domestic: NTK · GLX · VNMEP · IMP · MEPCO · International: ECA (TNR) · EID (Sinabu) · EMC (Mey Foong) · EPH (Aire Focus/Greentech) · ETL (Wind Control) · EUY (Vitrilan) · EAL (Plasticade) · EQC (QC Mfg).
